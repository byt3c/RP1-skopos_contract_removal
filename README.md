# RP1-skopos_contract_removal
Script to remove maintenance contract from RP1 - skopos mod.

**Usage :** python remove_skopos_maintenance_contracts.py input.sfs output.sfs level
input.sfs: your original save.
output.sfs: new file.
level: desired contract level to clear 1 or 2 or 3

Script will create sfslog.txt which contain run log.

**Note :** script will remove recurring contracts as well as initial target ones, so do this only when you close the program. Running this script while program is active will cause all of its initial contracts to be removed and you will need to do them again!
